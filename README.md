# Smriti-Setu (Dementia & Memory Assistance Platform)

An AI-powered cognitive and memory assistance web platform designed to empower individuals with Alzheimer's and dementia while providing robust support tools for family members and caregivers.

🌐 **Live Demo:** [https://dementia-memory-assistance-platform.vercel.app/](https://dementia-memory-assistance-platform.vercel.app/)

---

## 🚀 Key Features

* **AI Cognitive Gaming & Memory Aids:** Interactive exercises and games built to stimulate cognitive functions and slow memory decline.
* **Daily Routine Management:** Personalized scheduling and reminders to help patients easily navigate their day-to-day activities.
* **Caregiver Dashboard:** A dedicated companion interface that allows caregivers and family members to monitor routines, track medications, and manage care effectively.
* **Senior-Friendly Accessibility:** Thoughtfully designed with features like senior-friendly typography, speech engines, and accessible layouts to ensure a seamless user experience.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
* **Styling & Typography:** Custom CSS / Lexend font integrations
* **Deployment:** Vercel
